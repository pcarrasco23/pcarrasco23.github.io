04. // selected projects
[ 01 ]

TrialRT

AI in Healthcare — Graduate Final Project — University of Texas at Austin

An agentic pipeline that matches patients to clinical trials from their FHIR health records. LLM agents run over a hybrid retrieval stack — BM25 sparse plus MedCPT dense embeddings in Qdrant — across ClinicalTrials.gov and TREC 2021 data, served by a REST API with concurrent Postgres-backed workers and an audit dashboard.

[ 02 ]

Health Anomaly Detection

AI in Healthcare — Self Learning Tutorial — University of Texas at Austin

An anomaly-detection system that flags users whose smartwatch health patterns drift from healthy norms. Autoencoder neural networks — a feedforward model and an LSTM sequence model — are trained only on healthy users, so a high reconstruction error signals an anomaly, with per-feature attribution pinpointing which metrics (heart rate, sleep, stress, activity) drive it.

code → kaggle → slides →
[ 03 ]

Sutro Baths AR Tour

Winner, AR — Google Immersive Geospatial Challenge

A location-anchored AR walking tour of the Sutro Baths ruins in San Francisco. Using Google's Geospatial Creator and Map Tiles SDK, a historically accurate 3D reconstruction is pinned to the real site — visitors follow an illuminated path between info stops and use in-app sliders to reveal how the 1890s bathhouse changed over time. Built in Unity with models sculpted in Blender.
